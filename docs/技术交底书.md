# 技术交底书：基于目标试验模拟的中医药辅助治疗NSCLC真实世界研究框架

---

## 一、技术概述

### 1.1 技术名称
基于目标试验模拟（Target Trial Emulation）的中医药辅助治疗非小细胞肺癌（NSCLC）真实世界证据研究框架

### 1.2 技术领域
医疗人工智能、因果推断、中医药循证医学、真实世界研究（RWE）

### 1.3 技术背景与问题
中医药（TCM）作为NSCLC辅助治疗在中国广泛应用，但现有证据质量偏低：
- 回顾性研究设计缺乏前瞻性目标，因果推断能力不足
- 混杂偏倚严重（适应症偏倚：更健康的患者更倾向使用TCM）
- 存活时间偏倚（immortal time bias）：诊断到TCM开始之间的时间间隔未正确处理
- 缺乏标准化研究方案，结果可重复性差
- GRADE评级多为低或极低

目标试验模拟（TTE）由Hernan和Robins于2016年提出，是利用观察性数据模拟随机对照试验的系统方法论框架。2024年NEJM发表了关于TTE的方法学综述，标志着该方法在顶级医学期刊和监管层面的成熟认可。

### 1.4 发明目的
提供一套完整的、自动化的、可复现的目标试验模拟框架，用于从真实世界电子健康记录（EHR）数据中估计中医药辅助治疗NSCLC的因果效应，解决传统回顾性研究的方法学缺陷。

## 二、核心技术方案

### 2.1 目标试验模拟框架

#### 2.1.1 概念
目标试验模拟的核心思想是：在分析观察性数据之前，先定义一个我们希望进行但无法进行的理想随机对照试验（目标试验），然后利用观察性数据尽可能模拟该试验的设计要素。

#### 2.1.2 目标试验协议要素

| 要素 | 定义 |
|------|------|
| 合格标准 | 年龄>=18岁；组织学确诊NSCLC（IIIB-IV期）；ECOG 0-2分；接受一线含铂化疗 |
| 治疗策略 | (A) 含铂化疗 + 中药辅助治疗 >=2个周期 vs. (B) 含铂化疗单用 |
| 分配机制 | 基于EHR中的观察性分配；假定在测量协变量条件下可忽略（可交换性） |
| 结局指标 | 主要：总生存期（OS）；次要：无进展生存期（PFS）、客观缓解率（ORR）、生活质量（QoL）、不良事件 |
| 随访起点 | 首次化疗日期（时间零点），TCM需在60天内开始（宽限期） |
| 随访终点 | 死亡、失访或行政删失（36个月） |
| 因果对比 | 平均处理效应（ATE）和按方案效应 |
| 分析计划 | IPW、AIPW、g-computation；未测量混杂敏感性分析 |

#### 2.1.3 时间零点定义与存活时间偏倚处理
- **问题**：回顾性研究中，患者从化疗开始到接受TCM之间存在等待期，这段时间内患者存活（即"存活时间"），若处理不当会导致TCM组系统性偏好的存活偏倚
- **解决方案**：采用克隆-删失（cloning + censoring）方法
  - 将每位患者克隆到两个治疗臂
  - 根据实际接受的治疗确定分析臂
  - 在患者偏离初始分配时进行条件删失
  - 使用IPW校正因删失引入的选择偏倚

### 2.2 因果推断引擎

#### 2.2.1 逆概率加权（IPW）

**原理**：通过构建处理模型（倾向评分），用概率权重平衡治疗组之间的混杂因素分布。

**数学表达**：
- 倾向评分：e(X) = P(TCM=1 | X)，其中X为混杂因素向量
- 稳定化权重：SW_i = [P(TCM_i)] / [e(X_i)] （处理组）; SW_i = [1-P(TCM_i)] / [1-e(X_i)] （对照组）
- 加权平均处理效应：ATE = E[Y(1)] - E(Y(0)]，其中E[Y(a)] = (1/n) * sum(SW_i * Y_i * I(A_i=a))

**处理模型选择**：
- 主分析：逻辑回归（可解释性）
- 敏感性分析：梯度提升机（GBM）、随机森林（RF）
- 超级学习器（SuperLearner）：集成多种模型自动选择最优

**权重处理**：
- 截断：在第1和第99百分位数截断，减少极端权重影响
- 诊断：标准化均值差（SMD < 0.1表示良好平衡）

#### 2.2.2 增强逆概率加权（AIPW）

**原理**：双重稳健估计器——只要处理模型或结局模型中有一个正确，估计即一致。

**数学表达**：
mu_AIPW(a) = (1/n) * sum[ I(A_i=a)/e_hat(X_i) * (Y_i - mu_hat(a,X_i)) + mu_hat(a,X_i) ]

**优势**：
- 相比IPW，对倾向评分模型误设更稳健
- 相比g-computation，对结局模型误设更稳健
- 效率更高（方差更小）

**实施细节**：
- 结局模型使用灵活机器学习方法（SuperLearner集成：LASSO、RF、XGBoost、GLM）
- 交叉拟合（cross-fitting）避免Donsker条件限制（Chernozhukov et al., 2018）
- 将数据分为K折，每次用K-1折训练模型，第K折做预测

#### 2.2.3 G-计算（G-Computation）

**原理**：参数化g公式，通过拟合结局模型，在假设的治疗干预下模拟反事实结局分布。

**实施步骤**：
1. 拟合条件结局模型 E(Y | A, X)
2. 对每位患者，在a=1和a=0下分别预测反事实结局
3. 取平均得到群体水平因果效应
4. Bootstrap（1000次迭代）计算置信区间

**时变处理扩展**：对于TCM使用时间变化的场景，采用参数化g公式处理序贯可交换性假设。

#### 2.2.4 未测量混杂敏感性分析
- **E值计算**（VanderWeele and Ding, 2017）：量化需要多大强度的未测量混杂才能推翻当前结论
- **概率偏倚分析**（Lash et al., 2009）：对偏倚参数设定先验分布，通过Monte Carlo模拟校正
- **临界点分析**：系统性调整假设参数直至结论逆转

### 2.3 生存分析模块

#### 2.3.1 主要分析方法
- **加权Kaplan-Meier估计器**：使用IPW权重构建调整后的生存曲线
- **加权Cox比例风险模型**：估计风险比（HR）及95%置信区间
- **限制性平均生存时间（RMST）**：在12、24、36个月时间点计算RMST差异，不依赖PH假设

#### 2.3.2 补充分析
- **竞争风险分析**（Fine-Gray模型）：区分癌症死亡与其他原因死亡
- **里程碑分析**（Landmark analysis）：在3、6、12个月里程碑点评估，进一步处理存活时间偏倚
- **亚组分析**：按分期、组织学类型（腺癌vs鳞癌）、TCM类型、治疗持续时间

#### 2.3.3 比例风险假设检验
- Schoenfeld残差检验
- 若PH假设不成立，采用时变系数模型或RMST作为替代

### 2.4 成本效益评估模块

#### 2.4.1 分析框架
- **视角**：医疗卫生系统视角（中国医保报销体系）
- **时间范围**：终生，年贴现率3%
- **模型结构**：分区生存模型（PFS -> 进展 -> 死亡）

#### 2.4.2 成本测算
- 直接医疗成本：化疗药物、中药制剂、住院费、监测费、不良反应处理费
- 单位成本来源：国家医保药品目录价格、医院收费数据
- 间接成本：生产力损失（人力资本法）

#### 2.4.3 效果测算
- 质量调整生命年（QALY）：通过EQ-5D-5L效用值计算，从EORTC QLQ-C30映射
- 生命年增益（LYG）

#### 2.4.4 经济评价指标
- 增量成本效果比（ICER）= 增量成本 / 增量QALY
- 支付意愿阈值：3倍人均GDP（约258,000元/QALY）
- 概率敏感性分析（PSA）：10,000次Monte Carlo迭代，绘制成本效果可接受曲线（CEAC）和成本效果前沿（CEAF）
- 单因素确定性敏感性分析：龙卷风图
- 完全信息期望值分析（EVPPI）：评估收集更多信息的价值

### 3.1 整体架构



### 3.2 模块详细设计

#### 模块1：数据接入与标准化
- 输入：原始EHR数据（HL7 FHIR / 自定义CSV）
- 处理：ICD-10编码映射、TCM编码标准化、缺失数据插补（多重插补MICE）
- 输出：标准化分析数据集

#### 模块2：目标试验协议映射
- 输入：标准化数据 + 目标试验协议配置（YAML/JSON）
- 处理：合格标准筛选、时间零点定义、克隆-删失实施
- 输出：分析就绪数据集（两个虚拟治疗臂）

#### 模块3：因果推断引擎
- 输入：分析就绪数据集 + 混杂因素列表
- 处理：
  - 倾向评分估计（多种模型）
  - 权重计算与截断
  - 平衡诊断
  - IPW / AIPW / g-computation 估计
  - 置信区间（Bootstrap / Sandwich估计量）
- 输出：因果效应点估计与区间估计

#### 模块4：生存分析
- 输入：加权数据集
- 处理：加权KM曲线、加权Cox回归、RMST、竞争风险分析
- 输出：生存曲线图、HR估计、RMST差异

#### 模块5：成本效益评估
- 输入：生存分析结果 + 成本数据 + 效用数据
- 处理：分区生存模型、ICER计算、PSA
- 输出：ICER估计、CEAC图、龙卷风图、EVPPI

#### 模块6：报告生成
- 自动生成符合STROBE-TTE扩展的报告
- 自动生成可视化结果
- 自动生成敏感性分析汇总表

## 四、与传统回顾性研究的对比

### 4.1 方法学对比

| 维度 | 传统回顾性研究 | 本框架（TTE） |
|------|--------------|-------------|
| 研究设计 | 无预设目标试验协议 | 明确定义目标试验协议（7要素） |
| 时间零点 | 常未明确定义，易引入存活时间偏倚 | 严格定义索引日期，克隆-删失处理 |
| 混杂控制 | 单一PSM或分层分析 | 多重方法（IPW/AIPW/g-comp），双重稳健 |
| 倾向评分 | 简单逻辑回归，无模型选择 | SuperLearner集成学习，自动模型选择 |
| 权重诊断 | 很少报告 | 标准化均值差、权重分布可视化 |
| 未测量混杂 | 很少系统评估 | E值、概率偏倚分析、临界点分析 |
| 生存分析 | 简单KM和Log-rank | 加权KM、加权Cox、RMST、竞争风险 |
| 经济评价 | 罕见整合 | 内置CEA模块 |
| 可重复性 | 低（代码和数据不可获取） | 高（完整代码、Docker容器、配置驱动） |
| 报告标准 | 不一致 | 符合STROBE-TTE扩展 |

### 4.2 因果推断能力对比

| 特征 | 传统方法 | TTE框架 |
|------|---------|---------|
| 因果效应类型 | 关联（非因果） | 平均处理效应（ATE）-因果 |
| 假设透明度 | 隐含假设 | 明确列出所有假设并可检验 |
| 敏感性分析 | 无或简单的亚组分析 | 系统性的多重敏感性分析 |
| 模型不确定性 | 单一模型 | 多模型比较、交叉拟合 |
| 结果解释 | 条件效应 | 边际因果效应 |

### 4.3 临床转化价值对比

| 价值维度 | 传统方法 | TTE框架 |
|---------|---------|---------|
| 监管接受度 | 低 | 高（符合FDA/NMPA RWE框架） |
| 临床指南证据等级 | 低-极低 | 中等（可作为RCT替代证据） |
| 医保决策支持 | 有限 | 完整（整合CEA分析） |
| 学术发表影响力 | 低分期刊 | 可投稿高影响力期刊（NEJM方法论系列、TIRS） |

## 五、创新点

1. **首次将TTE框架应用于中医药领域**：填补TCM因果推断的方法学空白
2. **双重稳健估计器（AIPW）+ SuperLearner**：灵活的数据驱动建模，减少模型误设风险
3. **集成经济评价**：在同一框架内完成临床效果和成本效益分析
4. **存活时间偏倚的系统处理**：克隆-删失+IPW联合方法
5. **开放源代码、可复现**：Docker容器化，配置驱动，支持多中心扩展
6. **对接监管需求**：符合NMPA和FDA的RWE框架要求

## 七、风险与局限性

| 风险 | 说明 | 缓解措施 |
|------|------|---------|
| 残余混杂 | 未测量的混杂因素可能仍影响估计 | E值、概率偏倚分析、临界点分析 |
| 数据质量 | EHR数据可能不完整或有错误 | 多重插补、数据质量审计、敏感性分析 |
| TCM异质性 | 多种方剂和剂量，难以统一分析 | 分层分析、TCM类型亚组分析 |
| 外推性 | 结果可能仅适用于中国医院环境 | 多中心设计、外部验证 |
| 假设违反 | 可交换性/正性/一致性假设可能不满足 | 诊断检验、敏感性分析 |
